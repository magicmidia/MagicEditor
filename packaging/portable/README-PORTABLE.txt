MagicEditor — Portable
======================

This folder / archive is a portable build: no installer required.

Usage
-----
1. Extract anywhere (USB drive, cloud folder, local disk).
2. Run MagicEditor.exe.
3. Settings are stored per-user via Windows QSettings
   (organization MagicEditor / application MagicEditor), not inside this folder.

Notes
-----
- No admin rights needed to run.
- Uninstall = delete this folder (and optionally clear app settings from the Registry
  under HKCU\Software\MagicEditor if you want a full wipe).
- For a system-wide install with Start Menu shortcuts, use the .msi package instead.
